FaceSwap Studio Camera — 虚拟摄像头组件

这个组件会在 Windows 中添加名为 FaceSwap Studio Camera 的摄像头，供支持
DirectShow 的 64 位或 32 位桌面软件选择。安装组件需要管理员权限。

准备通过视频通话或直播软件输出时，再安装这个组件。主程序不会自动安装或注册它。

升级或卸载前，请先关闭正在使用此摄像头的通话、直播软件。
如需移除，请打开 Windows 设置 → 应用 → FaceSwap Studio Camera。
卸载主程序不会同时移除此组件；它采用独立的设备标识，不会替换 UnityCapture 或 OBS。

此组件当前为预览版。安装成功或本地像素传输检查通过，并不代表微信、WhatsApp 等
所有软件均已通过兼容测试。请以目标软件的实际接收画面为准。

基于 UnityCapture；来源与许可见随附的 LICENSE.txt 和 UPSTREAM.md。
