# 推理部署清单（RTX 4090 / DeepFaceLive 实时）

目标：现场机加载专模 `.dfm`，摄像头低延迟预览；外层可用 `face-swap-studio` 做工程/授权壳。

## 0. 现场机基线
- [ ] Win11 x64 + **RTX 4090 24GB**（4080 SUPER 16GB 可试用，旗舰演示优先 4090）
- [ ] 最新可用 NVIDIA 驱动；`nvidia-smi` 正常
- [ ] 摄像头：1080p@30 可稳出流（USB 带宽别跟多设备抢）
- [ ] 关闭无关占 GPU 程序（浏览器硬件加速、其他 AI 工具）

## 1. 软件安装
- [ ] 安装 **DeepFaceLive**（与导出 `.dfm` 的 DFL 版本匹配）
- [ ] （可选）安装本仓库 `face-swap-studio`：`scripts\setup-win.bat` → `scripts\start-win.bat`
- [ ] 壳与引擎先**并列运行**：壳管项目/授权日志，DFL 管真换脸；打通 IPC/启动器放下一迭代

## 2. 模型与工程
- [ ] 拷贝训练交付的 `model.dfm` + `dataset_manifest.json`
- [ ] 一人一模、目录隔离：`projects/<show>/<character>/model.dfm`
- [ ] 预览水印开关默认开（片场防误外传）

## 3. DeepFaceLive 运行参数（建议起点）
- [ ] 输入：摄像头或采集卡；先 **1080p** 再冲更高
- [ ] 开启 GPU；监控显存与温度（长拍注意机箱风道）
- [ ] 脸部增强/锐化适度：过强会「假白」、过弱会糊
- [ ] 记录实际延迟：端到端（摄像头→预览）目标「可跟嘴型」；接受数十 ms 级，不承诺零延迟

## 4. 现场验收标准（与技术调研对齐）
- [ ] **角度**：正面优秀；±30° 可接受；大侧脸允许掉质量但需说明
- [ ] **光照**：正常棚灯稳定；逆光/频闪单独测
- [ ] **嘴型**：说话 1 分钟无明显错位、牙齿乱闪
- [ ] **遮挡**：手挡脸/麦挡脸时的行为（冻结/降级）可预期
- [ ] **一致性**：连拍 5 分钟身份不「漂移成路人」

## 5. 性能档位（4090 经验预期）
| 档位 | 分辨率 | 用途 |
|------|--------|------|
| 稳妥 | 1280×720 / 1080p | 剧组预览、对戏 |
| 冲击 | 1440p | 演示机、素材够好时 |
| 谨慎 | 4K | 易爆延迟/显存，不作为默认交付 |

## 6. 故障速查
- [ ] 黑屏/无脸：摄像头权限、占用、分辨率
- [ ] 极卡：驱动、功耗墙、同时多路推理
- [ ] 不像：回查训练数据与 `.dfm` 版本，而不是只拧预览滑条
- [ ] 崩显存：降输入分辨率 / 关增强

## 7. 与 `face-swap-studio` 的边界
- 当前公开仓是**产品壳**（项目、授权勾选、占位预览）
- 真换脸 = DeepFaceLive + 客户/项目自备 `.dfm`
- 商用分发策略另案；本清单只解决技术跑通
