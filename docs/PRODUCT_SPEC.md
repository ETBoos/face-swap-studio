# FaceSwap Studio — 产品规格（剧组销售用简版）

**产品名**：FaceSwap Studio（剧组换脸预览工作站）  
**版本**：0.1.0（产品壳 MVP）  
**日期**：2026-09  

## 1. 一句话

给影视剧组用的 **授权素材 + 实时预览** 工作站：管项目、管授权、出参考帧；换脸能力通过接入成熟开源实时管线（DeepFaceLive / InsightFace）交付，而不是自研新模型。

## 2. 目标用户与场景

- **用户**：摄影指导助理、数字妆容/预览岗、后期预览、制片指定的授权操作员  
- **场景**：棚内/现场用摄像头看“换脸后大概长什么样”，导出参考帧给导演/化妆/VFX 沟通  
- **非目标**：互联网娱乐换脸 App、未授权肖像玩法、自动生成成片最终镜头

## 3. 功能清单

### 3.1 本版本已提供（壳）

| 功能 | 说明 |
|------|------|
| 项目管理 | 本地项目目录、元数据、素材与导出子目录 |
| 授权素材导入 | 图片导入到项目；需勾选授权清单 |
| 授权清单 UI | 合同级流程辅助（书面授权仍由剧组法务负责） |
| 摄像头预览占位 | 占位引擎：摄像头或合成画面 + 合规横幅 |
| 开始/停止预览 | 控制占位管线 |
| 导出参考帧 | 写入项目 `exports/`，可选水印 |
| 设置 | 分辨率、摄像头索引、GPU 设备备注、引擎选择 |
| 使用日志 | 本地 JSONL 审计桩 |
| Windows 安装脚本 | `setup-win.bat` / `start-win.bat` |

### 3.2 集成后交付（客户 GPU 机）

| 功能 | 说明 |
|------|------|
| 实时换脸预览 | DeepFaceLive（或 InsightFace 实时方案）适配器 |
| GPU 加速 | RTX 4080/4090，设备字符串可配 |
| 多素材切换 | 项目内授权脸切换（视引擎能力） |

### 3.3 明确不做（MVP）

- 训练新 SOTA 换脸模型  
- 云端人脸库 / 陌生人脸检索  
- 绕过授权的批量爬取或“一键网红脸”

## 4. 系统要求（销售机）

- Windows 10/11 + NVIDIA **RTX 4080 或 4090**  
- 32 GB RAM 建议、SSD  
- Python 3.11+（安装脚本处理依赖）  
- 授权摄像头/采集设备  

## 5. 合规与销售话术边界

- UI 固定横幅：**仅限授权影视用途**  
- 销售合同建议条款：素材授权义务在客户侧；软件提供清单、水印、日志辅助  
- **集成验收前**不得宣传“已具备影院级实时换脸”；应表述为“预览工作站 + 待现场集成引擎”  
- 开源引擎许可证需单独评审后再决定捆绑或“客户自备引擎”

## 6. 交付物形态

1. 本仓库源码 / 压缩包（`face-swap-studio-transfer.tar.gz`）  
2. Windows 一键安装与启动脚本  
3. 引擎适配接口文档（`engines/deepfacelive_stub.py`）  
4. 现场：在客户 4090 机器上完成 DFL 接入与验收（另行工时）

## 7. 路线图（简）

1. **0.1** 产品壳（当前）  
2. **0.2** DeepFaceLive worker IPC + 真预览验收  
3. **0.3** 多机位、LUT/监看友好导出、加固审计日志  
4. **1.0** 剧组试点包（授权模板 + 培训 + 维保）

## 8. 风险摘要

| 风险 | 缓解 |
|------|------|
| 未授权滥用 | 合同 + UI 清单 + 水印 + 日志；拒绝无授权部署 |
| 开源许可证 | 法务评审；可改为客户自备 DFL |
| 性能预期 | 以现场 4080/4090 实测 FPS 为准，不写死营销数字 |
| 与成片品质落差 | 定位为“预览沟通工具”，非最终 VFX 成片 |


## 3.3 双模式（2026-09 更新）

| 模式 | 后端 | 用户动作 |
|------|------|----------|
| 简易 | FaceFusion | 导入目标脸，简单配置即可预览 |
| 顶级 | DeepFaceLive | 导入训练好的 `.dfm` 后实时预览 |

壳负责模式切换；真推理分别由 FaceFusion / DeepFaceLive 适配器在 GPU 机接线。
