# 训练清单（RTX 4090 / DeepFaceLab → `.dfm`）

目标：为**指定真人**训出高像真度 SAEHD 专模，导出供 DeepFaceLive 使用的 `.dfm`。

## 0. 机器基线
- [ ] Win11 + NVIDIA 驱动（建议较新 Studio/Game Ready）
- [ ] RTX 4090 24GB，CUDA 正常（`nvidia-smi` 可见）
- [ ] 磁盘：训练数据 + 模型建议预留 **≥200GB** 快盘（NVMe）
- [ ] 安装 DeepFaceLab（官方/社区维护的 CUDA 版包），路径固定、不要装中文空格混乱目录

## 1. 数据采集规格（与验收对齐）
- [ ] 目标人物：**已获肖像授权**的多角度素材（即便暂不谈商用，技术验收也要多样本）
- [ ] 建议量级：清洗后可用脸图 **3000–8000+**（少了像真度上限会掉）
- [ ] 覆盖：正面 / 左右侧 30–45° / 俯仰小角度 / 说话张嘴 / 微笑 / 不同光照
- [ ] 避免：重度遮挡、运动模糊、极低分辨率、强美颜滤镜脸

## 2. 数据清洗
- [ ] `video` → `frames` 抽帧（按镜头分段，别一把梭）
- [ ] 人脸检测 + 对齐（DFL 工作流：`data_src` / `data_dst` 按项目约定）
- [ ] 人工抽检：删错检、侧脸翻车、重影、非本人
- [ ] 最终统计：有效脸数、分辨率分布写入 `project_notes.md`

## 3. 训练（SAEHD）
- [ ] 新建 model：架构选 **SAEHD**（像真度优先的主流专模路线）
- [ ] 分辨率：优先 **128/160/224** 阶梯；4090 可冲更高，但先保证收敛稳定
- [ ] batch / dims：按显存从保守档起，OOM 再降；保持可复现配置快照
- [ ] 训练时长预期：**约 1–数天**（素材质量与目标像真度决定，别按小时验收）
- [ ] 定期预览：嘴型、侧脸、牙齿、发际线；烂了就回滚检查点而不是硬训到底

## 4. 导出
- [ ] 导出 DeepFaceLive 可用的 **`.dfm`**
- [ ] 记录：训练步数、loss 曲线截图、导出文件哈希、对应数据版本号
- [ ] 交付物目录示例：
  ```
  models/<person_id>/
    model.dfm
    train_config.json
    dataset_manifest.json
    previews/
  ```

## 5. 训练侧验收（交给现场前）
- [ ] 静帧：正脸 / 半侧 / 弱光各 20 张，主观「可认出是本人」
- [ ] 短视频：说话 30s，嘴型无明显糊牙/漂移
- [ ] 失败样例归档（遮挡、急转头），写入限制说明

## 6. 明确不做（本阶段）
- 不把 DFL 权重打进可随便分发的安装包当「内置能力」售卖（商用另议）
- 不在素材不足时承诺「直播级极像」
