# L3 绿联采集卡 · 小白用法（微信 PC 出站保底）

> 仅当 **L1 软件虚拟摄像头** 不通时再用。能 L1 就先别插卡。

## 关键概念（必读）

**普通 HDMI 一分二 / 分配器只复制同一路信号，不会自动多出一块「独立扩展桌面」。**  
若你用一分二：显示器和采集卡看到的是同一画面；要靠「换脸窗口全屏占满该画面」才能让卡吃到换脸内容。

**优先接法（推荐）**：独立显卡 **第二个 HDMI/DP** → 采集卡，Windows 显示设为 **扩展**，把预览窗拖到第二屏全屏。  
**镜像接法（次选）**：一分二镜像；必须保证换脸预览全屏盖住该镜像画面，否则卡会采到桌面/错误窗口。

## ① 接线
1. **推荐**：显卡空闲 HDMI/DP（必要时 DP→HDMI）→ 绿联卡 HDMI  
2. **次选**：主屏 HDMI → 一分二 → 一路显示器 + 一路绿联卡  
3. 绿联卡 USB/Type-C → 主机**后置口**（不要扩展坞/前面板）

到货后核对该型号说明书的 **USB 实际上传规格**（常见为 1080p60 MJPEG/YUY2，不一定等于盒面「4K60 输入」）。输入 4K ≠ 电脑端一定收到 4K。

## ② 让系统认出摄像头
1. 设备管理器 →「相机」或「图像设备」出现采集卡名  
2. 没有：换后置口、换线、重装；仍无 → 换货（必须是 UVC 摄像头类，不是仅录屏软件能用的私有协议卡）

## ③ 让换脸画面进卡
1. 显示设置：扩展（推荐）或确认镜像内容即换脸全屏  
2. DeepFaceLive：Stream output / 预览拖到采集那路屏 **全屏**  
3. 即用 Deep-Live-Cam：把它的预览/Live 窗口拖到采集屏全屏（静帧首帧在本壳预览窗，实时画面在 DLC 窗口）  
4. 微信只选 **采集卡设备名**，禁止选手头物理摄像头

## ④ 微信选设备
视频通话设置 → 摄像头 = 采集卡名

## ⑤ 自测三步
- [ ] 设备管理器有相机  
- [ ] OBS（Video Capture Device）能预览到换脸画面  
- [ ] 微信设置能看到同名设备  

再：测试画面出站 → 换脸出站 → 手机接听录屏（见 `REALTIME_ACCEPTANCE.md`）

## 排错
| 现象 | 处理 |
|------|------|
| 黑屏 | USB 带宽/口；改 MJPEG；关其他占摄像头程序 |
| 有设备但微信没有 | 重启微信；确认 UVC；试 L1；钉微信版本 |
| 采到桌面不是脸 | 预览未全屏到采集屏；扩展/镜像搞错 |
| 权限 | Windows 隐私 → 相机 → 允许桌面应用 |
| 被占用 | 关掉其他已打开该采集设备的软件 |
| 线材 | 换 HDMI 线；避免劣质转接 |
